# SawitBench — Riset Benchmarking Pembinaan & Pelatihan Industri Kelapa Sawit

Aplikasi web interaktif dan generator workbook Excel (`.xlsx`) 5 sheet untuk riset benchmarking program pendidikan, orientasi, pelatihan, dan pembinaan SDM industri kelapa sawit dari 11 institusi rujukan (termasuk kampus vokasi sawit, corporate university perkebunan, lembaga riset/regulator, dan SMA Taruna Nusantara).

## Akses Aplikasi (GitHub Pages)
Setelah GitHub Pages diaktifkan dengan sumber **GitHub Actions**, aplikasi dapat dibuka langsung melalui:
`https://anggiars-spec.github.io/Benchmark/`

## Menjalankan Secara Lokal
```bash
npm install
npm run dev
```

## Build Produksi
```bash
npm run build
```
